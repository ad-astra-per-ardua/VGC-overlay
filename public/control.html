프리셋 — 경기 데이터를 미리 만들어두고 당일엔 불러오기만

곡 목록·선수명·팀명·STRATEGY 후보를 통째로 저장합니다. 라운드별로 미리 만들어두면 송출 당일엔 클릭 한 번으로 세팅이 끝납니다. 저장 위치는 서버 폴더의 presets/ 이고, 코드 파일을 덮어써도 지워지지 않습니다.

라운드 포맷

라운드별로 인원·곡 수가 다릅니다. 아래 버튼을 누르면 곡 슬롯 개수와 경기 화면 분할이 한 번에 맞춰집니다. 오버레이 선곡 배치는 곡 수를 보고 자동으로 바뀝니다 (2곡=세로 2장, 3곡=세로 3장, 5곡=오각형).

화면

STRATEGY

1~4라운드 통틀어 한 번만 사용합니다. 상대 선곡 목록의 STR 버튼으로 대상을 지정하세요. 밴된 곡에는 쓸 수 없고, STRATEGY 대상이 된 곡은 밴할 수 없습니다.

경기 중 — 영상

영상 하나에 4명이 이미 배치·싱크되어 있을 때 씁니다. 아래 4칸에 각 선수가 그 영상의 어느 사각형(원본 대비 %)에 있는지 지정하세요. 좌표를 눈으로 잡기 어려우면 캘리브레이션 도구 를 새 탭에서 열어 드래그로 잡고 값을 복사해오세요.

매 경기 배치가 항상 똑같다면(예: 영상 편집 시 1P를 항상 맨 왼쪽으로 고정) 아래 프리셋으로 한 번에 채우고 다시는 손댈 필요 없습니다. 슬롯 순서(1~4번)가 곧 화면 왼쪽부터의 순서가 됩니다.
